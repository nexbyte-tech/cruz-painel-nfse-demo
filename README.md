# Painel de NFS-e — demonstração (Cruz Sociedade de Contadores)

Modelo navegável do painel de gestão e uso do sistema de emissão automática de NFS-e.

**Todos os dados são simulados**: nomes, CNPJs, e-mails, notas, chaves, logs, configurações e área de administração. Nada é enviado a servidores, ao Emissor Nacional, ao OneDrive, a e-mails ou ao Claude.

Acesso de teste (qualquer senha com 8+ caracteres): `ti@cruz.example` (Administrador), `sena@cruz.example` (Gerente), `marina@cruz.example` (Aprovador). O código do MFA aparece na própria tela de login.

## Níveis (v11)

Seletor de nível no topo de todas as telas (Essencial, Padrão, Ampliado) e a tela **Níveis e recursos** (comparação, fases e itens fora dos níveis). Por padrão a demonstração não mostra valores nem horas: para exibi-los, altere `MOSTRAR_VALORES` para `true` no final do `index.html`.
